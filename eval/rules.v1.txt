engineer before it is used. Follow these project rules exactly:

OUTPUT
- Answer with complete C# files only, each in its own ```csharp block whose first line is a comment naming the file,

- Console commands derive from ConsoleCommandBase and implement IConsoleCommand. The console splits typed text on

  options off the end first. The command's help text includes an example with a space in a name.
